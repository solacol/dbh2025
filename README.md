# Challenges for DBH 2025
Challenges contributed to event [`Deutschlands Bester Hacker 2025`](https://deutschlands-bester-hacker.de/)

## Note of Transparency
The author has initially contributed parts of the challenges to former (closed/private) CTF events in a different version or constellation. Certain limitations have prevented an official public release. Caused by this and challenge adjustments/reworks, it should not have been too easy to use possible leaked write-ups. The fact was known to the organizers of DBH25 before.
